데이터 수집
소상공인시장진흥공단 상가업소 데이터(650,081행)에서 고양시 편의점 951개 추출. 국토교통부 공동주택 단지 목록에서 300세대 이상 345개 단지 필터링.

지오코딩
카카오 지도 REST API로 아파트 도로명주소 → 위경도 좌표 변환. 345개 중 325개 성공 (약 25.3만 세대 커버).
Kakao REST API requests

공백 분석
고양시 전역을 500m 격자로 분할 후 각 격자점에서 가장 가까운 편의점까지 거리 계산. 행정동별 편의점 간 평균 최근접 거리로 공백 심각도 점수화.
numpy scipy cdist
04
보로노이 분석
편의점 좌표 기반 보로노이 다이어그램 생성 후 Shapely로 고양시 경계 클리핑. KD-Tree로 각 아파트 단지를 최근접 편의점에 매핑해 담당 세대수 합산.
scipy Voronoi cKDTree shapely
