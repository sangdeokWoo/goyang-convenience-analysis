# 고양시 편의점 최적 입지 분석

> 공공데이터 기반 편의점 공백 지역 탐지 및 신규 입지 추천 프로젝트

**분석 결과 웹사이트:** https://sangdeokwoo.github.io/goyang-convenience-analysis/

---

## 프로젝트 개요

경기도 고양시의 편의점 분포 데이터와 공동주택 세대수 데이터를 결합하여,
편의점이 부족한 공백 지역을 탐지하고 신규 입지를 추천하는 데이터 분석 프로젝트입니다.

## 분석 결과 요약

- 분석 대상 편의점: **921개** (CU 280 / GS25 276 / 세븐일레븐 214 / 이마트24 75 / 기타 76)
- 분석 대상 아파트: **325개 단지 / 약 25.3만 세대** (300세대 이상)
- **주거지역의 97.9%, 아파트 세대의 98.9%가 편의점 400m(도보 5분) 안** — 거리상 공백은 거의 없음 (v2)
- 주거지 → 최근접 편의점 평균 거리: **150m**
- 공백 점수 1위: **삼송1동** (주거지 22%가 400m 밖) · 수요 대비 공급 최하위: **탄현2동** (편의점 1곳당 1,335세대)
- CU · GS25 시장 점유율: 각 **30.4% / 30.0%** (사실상 양강 구도)

> v1에서 보고했던 "커버리지 28.4%", "편의점 최대 담당 4,320세대"는 계산 방식·데이터 문제로 과장된 값이었습니다.

## v2 재분석 (2026-11)

### v1에서 발견한 문제

| # | 문제 | 영향 |
|---|------|------|
| 1 | 공백 점수 = 동 안 **편의점끼리의** 평균 최근접 거리 ÷ 편의점 수 | 주민이 얼마나 먼지가 아니라 편의점 간 간격을 측정. 수요(세대수) 미반영. 위경도에 111,000만 곱해 경도 방향 거리도 왜곡 |
| 2 | 커버리지 격자를 위경도 **사각형 전체**에 깔음 | 산·농지·한강까지 '미커버'로 집계 → 28.4%로 과소 추정. 추천 부지가 산·공원 위에 찍힘 |
| 3 | 원본 노트북이 편의점·아파트를 **위도 37.57~37.73 / 경도 126.74~126.97**로 걸러 저장 | 가좌·송포동 서쪽, 덕양구 북쪽 끝 데이터 누락 → '편의점 0개' 오판 위험 |
| 4 | Overpass 행정동 경계를 outer 웨이 좌표 **순서 없이 이어 붙임** | 경계가 꼬여 면적이 틀림 → 밀도 지도에 "일산2동 5,575개/km²" 같은 값 |
| 5 | 세븐일레븐 3곳(`세븐일레븐일산동구` ×2, `세븐일산동구백석점`)이 **같은 좌표** | 보로노이에서 한 셀로 합쳐져 "단일 편의점 4,320세대 담당"으로 과장 |
| 6 | CartoDB 배경지도가 API 키를 요구하도록 바뀜 | 모든 지도에 "API KEY REQUIRED" 워터마크 |
| 7 | 원본 CSV가 저장소에 없고 스크립트가 HTML을 정규식으로 파싱, 경로가 다른 PC에 고정 | 재현 불가 |

### v2에서 바꾼 것

- **데이터 복원**: 기존 HTML 지도에서 편의점 921개·아파트 325단지를 CSV로 복원 (`scripts/extract_data.py`)
- **경계·주거지역**: OSM에서 행정동 44개 경계와 주거지역(landuse=residential)을 받아 shapely `polygonize`로 올바르게 조립 (`scripts/fetch_osm.py`)
- **거리 계산**: EPSG:5179(미터 좌표계)로 투영한 뒤 계산
- **분석 영역**: 고양시 실제 경계 ∩ (데이터 수집 범위에서 400m 안쪽)에 100m 격자를 깔고, 주거지역 격자만 평가
- **접근성 지표 — 2SFCA** (Two-Step Floating Catchment Area)
  1. 편의점 j의 공급비 R_j = 1 / (반경 400m 안 아파트 세대수 합)
  2. 아파트 i의 접근성 A_i = Σ R_j (반경 400m 안 편의점) → "도보권 편의점 수 / 세대"
  3. 고양시 세대 가중 중앙값(1천 세대당 1.92개)보다 낮은 만큼을 **공급 부족 세대**로 집계
- **공백 점수**: 공급 부족 세대 비중 50% + 400m 밖 주거지 면적 비중 50%
- **입지 추천**: K-means 군집 중심 대신 **최대 커버리지 모형(탐욕법)**. 주거지(+100m) 격자 중 공백 점수를 가장 많이 줄이는 곳을 차례로 고르고, 고를 때마다 그 자리에 편의점을 추가해 다시 계산 (같은 수요를 두 번 세지 않음)
- **배경지도**: 전 지도 CartoDB → Esri Canvas 타일로 교체
- **재생성한 지도**: `goyang_dong_density_map.html`, `goyang_coverage_map.html` (올바른 경계·수치), 신규 `goyang_gap_v2_map.html`

### 커버리지 비교

| 기준 | 400m 커버율 |
|------|-----------|
| v1: 위경도 사각형 500m 격자 | 28.4% |
| v2: 고양시 경계 안 전체 면적 | 47.2% |
| v2: **주거지역** | **97.9%** |
| v2: **아파트 세대** | **98.9%** |

### 한계

- 거리는 직선거리 (도로망·단지 출입구 미반영)
- 아파트는 단지 대표 좌표 1점. 300세대 미만 단지·빌라·단독주택 세대수는 없음 → 주거지 면적으로만 보완
- OSM 주거지역은 실제 주거지를 다 담지 못할 수 있음
- 고양시 밖(서울 은평·파주·김포) 편의점은 데이터에 없어 시 경계 부근 접근성은 다소 낮게 나올 수 있음
- 데이터 수집 범위 밖 구역(지도에 회색)은 판단 보류. 원본 상가 데이터를 `시군구명` 기준으로 다시 추출하면 해결됨

## 분석 파이프라인

```
공공데이터 수집
    ├── 소상공인 상가업소 데이터 (650,081행) → 고양시 편의점 921개
    └── 공동주택 단지 목록 → 300세대 이상 345개 → 카카오 API 지오코딩 → 325개

전처리
    ├── 브랜드 분류 (상호명 기반 정규화)
    └── 좌표 정제 (고양시 bbox 필터)

공백 분석
    ├── 고양시 500m 격자 생성
    ├── 격자점 → 최근접 편의점 거리 계산
    └── 행정동별 평균 최근접 거리 → 공백 심각도 점수화

보로노이 분석
    ├── 편의점 좌표 기반 보로노이 다이어그램 생성
    ├── Shapely로 고양시 경계 클리핑
    └── KD-Tree로 아파트 → 최근접 편의점 매핑 → 담당 세대수 합산

브랜드 세력권 분석
    └── 보로노이 구역 × 브랜드 색상 → 시장 점유 지형 시각화

수요압력 분석
    ├── 세대수 ÷ √담당면적 → 수요압력 점수 계산
    ├── 히트맵 시각화
    └── K-means 클러스터링 → 신규 입점 최적 위치 TOP 10 추천

서비스 권역 분석
    ├── 편의점별 반경 400m 서비스 원 시각화
    ├── Overpass API로 고양시 행정동 44개 경계 오버레이
    └── 격자 기반 커버리지 비율 계산 (v1 28.4% → v2 주거지 기준 97.9%)

공백 재분석 v2
    ├── HTML 지도 → CSV 데이터 복원, OSM 행정동·주거지역 경계
    ├── EPSG:5179 투영, 고양시 경계 안 100m 격자 (주거지역만 평가)
    ├── 2SFCA 접근성 → 공급 부족 세대, 400m 밖 주거지 → 공백 점수
    └── 최대 커버리지 모형(탐욕법) → 신규 입지 TOP 10

브랜드별 공백 분석
    ├── 브랜드별 최근접 거리 격자 계산
    ├── 브랜드 히트맵 레이어 (CU / GS25 / 세븐일레븐 / 이마트24)
    └── 1km+ 공백 비율: CU 51.6% / GS25 57.7% / 세븐일레븐 62.6% / 이마트24 69.7%

시각화 · 배포

    ├── Playwright로 지도 스크린샷 썸네일 자동 생성

```

## 주요 인사이트

1. **거리상 공백은 거의 없다** — 주거지의 97.9%, 아파트 세대의 98.9%가 편의점 400m 안. 고양시는 "편의점이 없는 곳"보다 "수요에 비해 적은 곳"을 봐야 하는 포화 시장
2. **삼송1동·식사동·효자동** — 공백 점수 1~3위. 삼송·지축 신도시와 위시티 일대에 400m 밖 주거지와 공급 부족 세대가 몰려 있음
3. **탄현2동** — 편의점 5개, 1곳당 1,335세대. 도보권 공급률이 1천 세대당 0.85개로 고양시 중앙값(1.92개)의 절반 이하
4. **추천 1위 삼송1동** — 힐스테이트 라피아노 삼송(452세대)의 최근접 편의점이 약 700m
5. **CU vs GS25** — 30.4% vs 30.0%로 사실상 양강 구도. 세븐일레븐(23.2%)과 격차 존재
6. **이마트24 공백 최대** — 1km 이상 공백 구역 69.7%로 4개 브랜드 중 가장 낮은 커버리지 (v1 브랜드 공백 분석, 사각형 격자 기준)
7. **v1 수치 정정** — 커버리지 28.4%는 산·농지 포함 격자 기준, "단일 편의점 4,320세대 담당"은 같은 좌표에 등록된 3개 점포가 합쳐진 값
