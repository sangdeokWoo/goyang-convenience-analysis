# 고양시 편의점 최적 입지 분석

> 공공데이터 기반 편의점 공백 지역 탐지 및 신규 입지 추천 프로젝트

**분석 결과 웹사이트:** https://sangdeokwoo.github.io/goyang-convenience-analysis/

---

## 프로젝트 개요

경기도 고양시의 편의점 분포 데이터와 공동주택 세대수 데이터를 결합하여,
편의점이 부족한 공백 지역을 탐지하고 신규 입지를 추천하는 데이터 분석 프로젝트입니다.

---

## 데이터 출처

| 데이터 | 출처 | 비고 |
|--------|------|------|
| 전국 상가업소 정보 | 소상공인시장진흥공단 공공데이터포털 | 편의점 위치 추출 |
| 공동주택 단지 목록 | 국토교통부 공공데이터포털 | 아파트 세대수 |
| 주소 → 좌표 변환 | 카카오 지도 REST API | 지오코딩 |
| 행정구역 경계 | 국가공간정보포털 | 고양시 필터링 |

---

## 분석 결과 요약

- 분석 대상 편의점: **921개** (CU 280 / GS25 276 / 세븐일레븐 214 / 이마트24 75 / 기타 76)
- 분석 대상 아파트: **325개 단지 / 약 25.3만 세대**
- 공백 심각 행정동: **TOP 10 도출**
- 편의점 최대 담당 세대수: **4,320세대** (세븐일레븐일산동구)
- 수요압력 최고 구역 영향 세대수: **50,370세대** (K-means 클러스터 1위)
- CU · GS25 시장 점유율: 각 **30.4% / 30.0%** (사실상 양강 구도)

## 분석 파이프라인

```
공공데이터 수집
    ├── 소상공인 상가업소 데이터 (650,081행) → 고양시 편의점 921개
    └── 공동주택 단지 목록 → 300세대 이상 345개 → 카카오 API 지오코딩 → 325개

전처리
    ├── 브랜드 분류 (상호명 기반 정규화)
    └── 좌표 정제 (고양시 bbox 필터)

공백 분석
    ├── 고양시 500m 격자 생성
    ├── 격자점 → 최근접 편의점 거리 계산
    └── 행정동별 평균 최근접 거리 → 공백 심각도 점수화

보로노이 분석
    ├── 편의점 좌표 기반 보로노이 다이어그램 생성
    ├── Shapely로 고양시 경계 클리핑
    └── KD-Tree로 아파트 → 최근접 편의점 매핑 → 담당 세대수 합산

브랜드 세력권 분석
    └── 보로노이 구역 × 브랜드 색상 → 시장 점유 지형 시각화

수요압력 분석
    ├── 세대수 ÷ √담당면적 → 수요압력 점수 계산
    ├── 히트맵 시각화
    └── K-means 클러스터링 → 신규 입점 최적 위치 TOP 10 추천

서비스 권역 분석
    ├── 편의점별 반경 400m 서비스 원 시각화
    ├── Overpass API로 고양시 행정동 44개 경계 오버레이
    └── 격자 기반 커버리지 비율 계산 (28.4%)

브랜드별 공백 분석
    ├── 브랜드별 최근접 거리 격자 계산
    ├── 브랜드 히트맵 레이어 (CU / GS25 / 세븐일레븐 / 이마트24)
    └── 1km+ 공백 비율: CU 51.6% / GS25 57.7% / 세븐일레븐 62.6% / 이마트24 69.7%

시각화 · 배포
    ├── Folium 기반 인터랙티브 지도 7종
    ├── Playwright로 지도 스크린샷 썸네일 자동 생성
    └── GitHub Pages 정적 배포
```

## 주요 인사이트

1. **탄현2동·성사2동** — 편의점 5개·4개로 고양시 최저. 주거 인구 대비 공급 심각 부족
2. **능곡동·원신동** — 편의점 수는 있으나 평균 거리 460m 이상으로 실질 접근성 낮음
3. **세븐일레븐일산동구** — 단일 편의점이 4,320세대 담당. 극단적 과부하
4. **CU vs GS25** — 30.4% vs 30.0%로 사실상 양강 구도. 세븐일레븐(23.2%)과 격차 존재
5. **수요압력 1위 구역** — 영향 세대수 50,370세대로 신규 입점 시 최대 수요 기대
6. **이마트24 공백 최대** — 1km 이상 공백 구역 69.7%로 4개 브랜드 중 가장 낮은 커버리지
7. **고양시 전체 커버리지** — 편의점 400m 반경 기준 격자점의 28.4%만 커버 (71.6% 미커버)
